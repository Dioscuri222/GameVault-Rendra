### 1. IDENTITAS & KONTEKS PROYEK (SESUAI `Tema.txt`)
- **Judul Aplikasi:** GameVault
- **Kategori / Tema:** Hiburan (Entertainment & Gaming Information Hub)
- **Author / Pemilik Proyek:** Rendra
- **Deskripsi Sistem:** Aplikasi hiburan berbasis Android bagi para gamer untuk mencari informasi game terbaru dan terpopuler. Memanfaatkan public API (**RAWG Video Games Database API**) untuk menampilkan detail game, rating, dan screenshot, serta menggunakan komponen UI **Jetpack Compose** untuk galeri gambar yang responsif (LazyVerticalGrid, HorizontalPager, dan AsyncImage Coil). Selain itu, sistem dilengkapi **REST API Backend buatan sendiri (Node.js/Express + PostgreSQL)** untuk autentikasi JWT, pemisahan peran (`ADMIN` vs `USER`), manajemen **Koleksi Kurasi Game**, **Ulasan & Rating Pengguna**, **Wishlist / Backlog Gamer**, serta **Local File Storage** untuk ekspor dan baca laporan koleksi game di perangkat.

### 2. KEPATUHAN TERHADAP `PEDOMAN PROJECT AKHIR PAM 2026`
Seluruh rancangan SRS dan implementasi kode wajib memenuhi seluruh persyaratan minimal pedoman:
1. **UI Framework:** 100% **Jetpack Compose** (Material 3) & multi-page routing menggunakan **Navigation Compose** (dilarang menggunakan XML Layout / framework lain).
2. **Arsitektur State Management:** Wajib menggunakan pola **MVVM** (`Model - Repository - ViewModel - UI Screen`).
3. **Authentication & Authorization:** Implementasi Register, Login, **Access Token (JWT)**, dan **Refresh Token** (`TokenAuthenticator`), serta **Role-Based UI & API** (`ADMIN` vs `USER`).
4. **Database & Entitas Relasional:** Menggunakan **PostgreSQL** (dilarang menggunakan SQLite/Room) dengan **minimal 4–5 entitas utama yang saling berelasi**:
   - `users` (`id_user`, `nama_lengkap`, `email`, `password_hash`, `gamer_tag`, `role` [`ADMIN`, `USER`], `refresh_token`, `created_at`)
   - `curated_collections` (`id_collection`, `title`, `category_tag`, `description`, `banner_url`, `created_by` FK `users`, `created_at`)
   - `collection_games` (`id_entry`, `collection_id` FK `curated_collections`, `rawg_game_id`, `game_title`, `cover_image`, `curator_note`)
   - `game_reviews` (`id_review`, `user_id` FK `users`, `rawg_game_id`, `game_title`, `rating_score` [1.0–5.0], `play_status` [`PLAYING`, `COMPLETED`, `DROPPED`], `review_text`, `created_at`, `updated_at`)
   - `user_wishlists` (`id_wishlist`, `user_id` FK `users`, `rawg_game_id`, `game_title`, `cover_image`, `released_date`, `metacritic_score`, `priority_level` [`HIGH`, `MEDIUM`, `LOW`], `notes`, `created_at`, `updated_at`)
5. **Minimal 5 Fitur CRUDS Penuh (Create, Read, Update, Delete, Search):**
   - **Modul 1 (`Auth & Session`):** Register, Login, Auto-Refresh Token, Logout, Update Profil.
   - **Modul 2 (`Explore Games — RAWG Public API`):** Read & Multi-Filter Search game terbaru/terpopuler/genre/platform (`GET /games`), Detail Game (`GET /games/:id`), dan Galeri Screenshot Responsif (`GET /games/:id/screenshots`).
   - **Modul 3 (`Curated Collections`):** CRUDS penuh oleh `ADMIN` dan Read/Search + lihat daftar game kurasi oleh `USER`.
   - **Modul 4 (`Game Reviews & Ratings`):** CRUDS penuh ulasan & skor rating game oleh `USER` (validasi kepemilikan `user_id` atau moderasi `ADMIN`).
   - **Modul 5 (`Gamer Wishlist / Backlog & Local File Storage`):** CRUDS penuh daftar wishlist game milik pengguna serta fitur simpan (*export*) dan baca kembali laporan koleksi/backlog ke penyimpanan lokal perangkat (`.txt` / `.pdf`).
6. **Keselarasan 100% SRS & Kode:** Setiap endpoint, nama tabel, kolom, validasi, dan alur pada kode wajib identik dengan dokumen SRS (menghindari penalti pengurangan nilai 50%).
7. **Struktur GitHub & Progress Bertahap:** Siapkan juga struktur repositori berformat `4NIMBelakang_GameVault` lengkap dengan file `README.md` berisi tabel progres mingguan (untuk mendukung minimal 30 commit bertahap, tidak push sekali jadi).
